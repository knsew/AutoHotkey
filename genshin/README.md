# 原神连招（精简包里的 genshin/ 部分）

精简包解压后不用另装 AutoHotkey：双击包根目录的“启动原神连招.bat”，
启动器会用包里 `bin/AutoHotkey64.exe` 拉起本目录的 `launcher.ahk`，
再由启动器拉起 `engine.ahk`。

启动器只管两件事：**脚本列表 + 热键修改**，别的都不做。

- 列表里看角色、连招、触发键、模式、状态；选中一套点“改热键”，
  输入 AHK 写法（`^1` = Ctrl+1，`^+1` = Ctrl+Shift+1，`none` = 停用），
  会直接改写对应 `.combo` 文件头的 `@trigger`，引擎在运行时自动重载生效。
- “启动引擎 / 停止引擎 / 重载引擎”只管引擎进程；关闭启动器窗口
  不停止引擎，引擎在托盘继续跑，停止请点“停止引擎”或在原神外按 End。
- 想手动改连招：直接改 `combos/*.combo`，格式见原管理器 README，
  改完在启动器里点“重载引擎”或托盘“重新加载连招”。

全局键（引擎，任何窗口都生效，因为是救命键）：F12 急停，Home 暂停/恢复，
End 退出引擎。连招热键只在原神窗口聚焦时生效。

口径（Ji 2026-10-30 定）：只按 60 帧做；触发键只用键盘组合，不用鼠标侧键；
60 帧做不了的见 `docs/ABANDONED.md`。来源见 `SOURCES.md`。

连招时序都没有真正跑过。首跑请先只开 1 套、在低风险场合测。
