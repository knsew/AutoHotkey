# 原神连招（精简包里的 genshin/ 部分）

精简包解压后不用另装 AutoHotkey、不用 bat：双击包根目录的
`GenshinLauncher.exe`（C 语言启动器），它会用包里
`bin/AutoHotkey64.exe` 拉起本目录的 `engine.ahk`。

启动器只管三件事：**看脚本列表、改快捷键、开始 / 停止连招**，别的都不做。

- 列表里看角色、连招、触发键、模式；点一套连招，再点“改快捷键”，
  输入好看的写法（`Ctrl+1`、`Ctrl+Shift+1`），会直接改写对应 `.combo`
  文件头的 `@trigger`，引擎在运行时自动重载生效；点“停用这套”就是停用。
- “开始连招 / 停止”只管引擎进程；关闭启动器窗口时，连招也会一起停止，
  不留一个不知道怎么关的后台进程。
- 想手动改连招：直接改 `combos/*.combo`，改完在启动器里重开连招即可。

全局键（引擎，任何窗口都生效，因为是救命键）：F12 急停，Home 暂停/恢复，
End 退出引擎。连招热键只在原神窗口聚焦时生效。

口径（Ji 2026-10-30 定）：只按 60 帧做；触发键只用键盘组合，不用鼠标侧键；
60 帧做不了的见 `docs/ABANDONED.md`。来源见 `SOURCES.md`。

**没在真机上验证过**：本机无 Windows / AutoHotkey / 原神，引擎、启动器、
连招时序都没有真正跑过。首跑请先只开 1 套、在低风险场合测。
宏类工具有封号风险，用不用由你自己定。
